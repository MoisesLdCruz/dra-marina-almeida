# Dra. Marina Almeida — Landing Page

Landing page de odontologia estética e saúde.

## Publicar no GitHub Pages (2 minutos)

1. Baixe o arquivo `index.html` completo (link na conversa).
2. No repositório, clique em **Add file → Upload files** e envie o `index.html` na **raiz** (substitua o atual).
3. Vá em **Settings → Pages**.
4. Em **Source**, escolha **Deploy from a branch**.
5. Branch: `main` · Pasta: `/ (root)` → **Save**.
6. Aguarde 1–2 minutos. A página ficará em:

**https://moisesldcruz.github.io/dra-marina-almeida/**
